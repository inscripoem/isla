Isla first interactive loop

This isolated demo connects a browser performer to the real M5 runtime, plays the registered fixed WAV assets through the real M1 PlaybackController, and displays subtitles and a mapped reaction. All audio observations are media events, not acoustic measurements.

Recovery

If playback was interrupted, for example by a disconnect or a page reload, the retained session can accept input but may be unable to produce new output. Recovery ends the current session and starts a fresh one that carries only confirmed history. It never replays audio, never clears unknown outcomes, and needs a manual Resume afterwards. This is your operator decision that you have ended playback; it is not a measured media result.
